# Neurodevelopment of Corticostriatal Circuits and Risk for Alcohol Use During the Transition from Adolescence to Adulthood
## Code Repository
### R_scripts
Contains code for all analyses and figures. Scripts should be run in numerical order...

00: Scripts to clean individual measures (i.e., neuroimaging, behavioral, surveys, ext)

01: Merging script

02: Harmonization script across sites and scanners and scanner upgrades

03: Analytic preprocessing (centering, factors, ext.)

04: K means clustering of alcohol variables (NOT INCLUDED IN CURRENT MANUSCRIPT)

05: GAM models (3 seeds with Gordon atlas of 333 parcels)

06: K means clustering of GAM model results

07: K means cluseting cleaning code

08: Main statistical analyses and figures

09: Specificity analyses with binge drinking, cannabis, and nicotine

### clean_data
Contains de-identified post-processed data
